# 🃏 Card Game Fullstack

Ce projet est une application fullstack de jeu de cartes.
Le backend fournit une API REST, et le frontend est une interface Angular.

## 📚 Technologies utilisées
- **Backend** : Java 17, Spring Boot, Maven
- **Frontend** : Angular, TypeScript, HTML/CSS

## ✅ Prérequis
- [Java JDK 17](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html) ou supérieur
- [Node.js](https://nodejs.org/) (version 18 recommandée)

## 🚀 Installation et lancement

### 1. Lancer le Backend (API)
Ouvrez un terminal à la racine du projet (`cardgame-fullstack`), puis exécutez :

```cmd
cd backend
mvnw.cmd spring-boot:run
```
### 2. Lancer le Frontend (Interface)

cd cardgame_front\cardgame
npm install
npm start
